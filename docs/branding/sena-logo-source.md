# Fuente del logo institucional SENA

| Campo | Valor |
| --- | --- |
| Activo por incorporar | Variante oficial independiente del logotipo SENA, en vector si está disponible |
| Fuente de autoridad | Manual de Identidad Visual SENA 2024 |
| URL | `https://historico.sena.edu.co/es-co/Documents/MANUAL_IDENTIDAD_VISUAL_SENA_2024.pdf` |
| Norma asociada | Resolución SENA 1825 de 2024 y Manual de Identidad Visual SENA 2024 |
| Consulta | 2026-11-21 |

Antes de incorporarlo en interfaz, la implementación debe descargar la variante independiente desde el canal institucional autorizado y contrastar fondo, variante, proporciones y zona de protección con el [Manual de Identidad Visual SENA 2024](https://historico.sena.edu.co/es-co/Documents/MANUAL_IDENTIDAD_VISUAL_SENA_2024.pdf). No debe redibujarse ni usarse como base para un logo generado.

Se descartó un GIF del normograma que combina el símbolo con el texto genérico “Nombre del programa”: no es el logo institucional independiente y no debe reutilizarse como tal.
