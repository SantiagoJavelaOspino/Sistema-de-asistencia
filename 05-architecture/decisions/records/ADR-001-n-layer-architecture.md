# ADR-001: Arquitectura de N capas

- **Estado:** Sustituido por [`docs/decisions/adr-004-n-layer-architecture-and-security-baseline.md`](../../../docs/decisions/adr-004-n-layer-architecture-and-security-baseline.md)
- **Fecha de sustitución:** 2026-11-21

## Decisión vigente

El Sistema de Asistencia SENA adopta una arquitectura de siete capas. La definición, los patrones permitidos y el estado de migración viven en [`docs/architecture/n-layer-architecture.md`](../../../docs/architecture/n-layer-architecture.md).

No utilizar este registro para introducir un modelo arquitectónico diferente.
